# Bloom Tasks — Week 3 Type-Safe Planner

Pages: Overview, My Tasks, Focus Room, Insights and Settings.

Features: add/edit/delete/complete tasks, due date, priority, search, filters, progress dashboard, focus timer presets, insights, responsive navigation, and localStorage persistence with runtime validation.

TypeScript: `script.ts` includes Task interface, Priority/Filter/Page types, typed functions, and validated localStorage data. `tsconfig.json` enables strict type checking.

Run: open `index.html` in a browser. To rebuild: `npm install` then `npm run build`.

GitHub Pages: upload all files to repository root → Settings → Pages → Deploy from a branch → main → /(root) → Save.


## Change colour theme
Open **Settings** from the sidebar and choose Sage, Sunshine, Lavender, Rose, Ocean, or Dark. Your selected theme is saved in your browser and remains selected after refresh.
